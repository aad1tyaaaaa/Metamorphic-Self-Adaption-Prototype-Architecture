Every GPT-2 variant, including static 12-layer GPT-2, scores 0.000 exact match on GSM8K; the pretrained dense Baseline D reaches only 0.050. GPT-2 small cannot solve that task, so GSM8K separates compute behaviour, not quality. On GSM8K the predictor also routes almost everything to deep, so the compute saving seen on short QA largely disappears. Baseline D uses a different tokenizer, so its answer perplexity is not comparable with the GPT-2 rows.

What this page does and does not do. The Task Analyzer heuristics, the f_theta forward pass (exported weights, 8→32→16→3), the confidence policy and the stability monitor are reimplemented here and genuinely execute on your input. Every loss, perplexity, latency and accuracy figure is a recorded measurement replayed from results/. This page does not run GPT-2.

Measured limitations.

  • Full MSA is the worst-quality GPT-2 variant tested; attention and FFN slicing are applied to pretrained weights with no retraining.
  • A pretrained dense model of similar size (Baseline D) answers far more short questions than any GPT-2 configuration.
  • Calibration targets come from prompt loss, which is not downstream task quality.
  • Latency was measured on a shared CPU; the routing baseline is slower than static at short sequences and faster only at 256 tokens.
  • Evaluation sets are small (60 short-QA, 40 GSM8K); small differences are not meaningful.
